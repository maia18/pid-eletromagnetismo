# 📐 Projeto de Inovação Docente: Eletromagnetismo & IA

Este repositório serve como uma demonstração do projeto desenvolvido no curso de Engenharia de Telecomunicações (UFC), sob a orientação do Prof. João Batista.

O objetivo do projeto é modernizar o ensino de Eletromagnetismo Aplicado por meio do desenvolvimento integrado de notebooks computacionais interativos e vídeos educativos apoiados por Inteligência Artificial.

## 🎯 Objetivos da Ferramenta
- Transformar conceitos abstratos e equações diferenciais em visualizações gráficas acessíveis.
- Proporcionar um ambiente interativo onde os estudantes possam manipular variáveis do campo eletromagnético em tempo real.
- Integrar ferramentas de IA para otimização da produção de roteiros e materiais em vídeo.

## 🛠️ Tecnologias Utilizadas
- **Google Colab:** Ambiente principal de desenvolvimento.
- **Python (Plotly & VPython):** Para simulações dinâmicas 3D e plotagem de dados vetoriais.
- **MathJax:** Para a formatação rigorosa de tabelas e resoluções matemáticas passo a passo.
- **IA Generativa:** Apoio na estruturação de mídias educacionais.
